Jawaban Pertanyaan Praktikum HTML Dasar

Berikut adalah daftar pertanyaan dan jawaban teori dari Modul Praktikum Pemrograman Web.

1. Apa fungsi deklarasi <!DOCTYPE html> pada dokumen HTML?

Deklarasi <!DOCTYPE html> berfungsi untuk memberikan instruksi kepada web browser bahwa dokumen yang sedang dibaca adalah dokumen HTML5 (standar versi terbaru HTML). Deklarasi ini memastikan agar browser dapat merender dan menampilkan halaman web dengan benar dan konsisten sesuai standar web modern.

2. Apa perbedaan antara tag, elemen, dan atribut pada HTML?

  • Tag: Adalah tanda penanda awal dan akhir dari sebuah bagian di HTML yang ditulis di dalam kurung siku (<...>, contohnya <p> atau </p>). Sebagian besar tag berpasangan.
  • Elemen: Adalah komponen utuh yang menyusun dokumen HTML, yang terdiri dari kombinasi tag pembuka, isi teks/konten di dalamnya, dan tag penutup (contoh: <p>Ini adalah isi teks</p>).
  • Atribut: Adalah informasi atau pengatur tambahan yang diletakkan di dalam tag pembuka untuk memberikan instruksi khusus pada elemen tersebut (contoh: src="images/profil.jpg").

3. Apa perbedaan <p> dengan <br>? Jelaskan penggunaannya.

  • Tag <p> (Paragraf): Digunakan untuk mengelompokkan sekumpulan kalimat menjadi sebuah paragraf utuh. Elemen <p> ini memiliki jarak (spasi atas dan bawah) secara otomatis di browser.
  • Tag <br> (Line Break): Digunakan hanya untuk memaksa teks berpindah ke baris baru di bawahnya tanpa membuat jarak paragraf baru.

4. Apa fungsi atribut href pada tag <a>?

Atribut href (singkatan dari hypertext reference) pada tag <a> berfungsi untuk menentukan alamat tujuan tautan (URL atau path file) yang akan dituju ketika teks atau objek link tersebut diklik oleh pengguna.

5. Apa perbedaan hyperlink ke halaman internal dengan hyperlink ke website eksternal?

  • Hyperlink Internal: Adalah tautan yang menghubungkan satu halaman web ke halaman web lain yang masih berada di dalam satu website/project yang sama (contoh: <a href="halaman2.html">Halaman 2</a>).
  • Hyperlink Eksternal: Adalah tautan yang menghubungkan halaman web kita ke situs web lain di luar project secara luas (contoh: <a href="https://www.google.com">Google</a>).

6. Apa fungsi atribut src dan alt pada tag <img>?

  • Atribut src (source): Berfungsi untuk menentukan lokasi jalur (path) atau URL dari file gambar yang akan ditampilkan.
  • Atribut alt (alternative text): Berfungsi untuk memberikan teks deskripsi atau alternatif yang akan muncul jika file gambar gagal dimuat oleh browser.

7. Apa perbedaan penggunaan <ul> dan <ol>?

  • Tag <ul> (Unordered List): Digunakan untuk membuat daftar item atau poin-poin yang tidak berurutan (menggunakan simbol titik/bullet).
  • Tag <ol> (Ordered List): Digunakan untuk membuat daftar item yang berurutan (menggunakan penomoran angka 1, 2, 3, dst).

8. Apa yang terjadi jika path gambar pada atribut src salah?

Jika lokasi jalur (path) atau nama file gambar pada atribut src salah atau tidak ditemukan, maka gambar tersebut tidak akan muncul. Browser akan menampilkan teks alternatif dari atribut alt atau ikon gambar rusak.

9. Mengapa struktur heading h1 sampai h6 perlu digunakan secara terstruktur?

Heading perlu digunakan secara terstruktur (mulai dari <h1> sebagai judul utama, <h2> untuk subjudul, dst.) agar struktur dokumen web mudah dibaca, memiliki hirarki informasi yang jelas, serta penting untuk optimasi SEO dan aksesibilitas web.

10. Apa fungsi komentar <!-- ... --> dalam kode HTML?

Komentar <!-- ... --> berfungsi untuk memberikan catatan, keterangan tambahan, atau dokumentasi di dalam baris kode. Komentar ini diabaikan oleh web browser dan tidak ditampilkan di halaman web.
